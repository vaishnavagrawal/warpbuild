Clashes, Gaps & Deviations

#TypeDescriptionResolution
1 Deviation Handoff says "RuntimeContext" — the current Mastra v1.52 API uses RequestContext (from @mastra/core/request-context), not RuntimeContext. The handoff doc uses the older name. Resolved. Used RequestContext per the installed API.
2 Deviation Model config via OpenAICompatibleConfig — the plan says "OpenAI-compatible provider wired via env" but doesn't specify the mechanism. Mastra 1.52 supports OpenAICompatibleConfig as a model config object ({ id, url, apiKey }) which avoids installing a separate AI SDK provider package. Resolved. Used OpenAICompatibleConfig directly: reads LLM_MODEL as the model string, LLM_BASE_URL as the endpoint, LLM_API_KEY for auth.
3 Gap No run_read_query tool available. Phase 3 delivers this tool. The agent's tools config returns an empty object for now. A file src/mastra/tools/run-read-query.ts already exists from Phase 3 work-in-progress but is not wired into the agent yet. Pending Phase 3 completion. Once done, import and add to the tools function in analyst-agent.ts.
4 Gap tRPC datasource and schema routers referenced but not yet built. The app router at packages/api/src/routers/index.ts imports datasourceRouter and schemaRouter from Phase 1/2 work that is still in progress. Pending Phases 1–2. No clash — Phase 4 uses direct drizzle queries, not tRPC, for the chat route.
5 Clash drizzle-orm version duplication in bun. Adding @nextjs-starter/db and drizzle-orm to apps/web initially caused TypeScript to see two incompatible copies of drizzle-orm types (different bun resolution hashes due to the pg peer dependency). Types from @nextjs-starter/db schema were incompatible with eq() from the local copy. Resolved. Added pg as a direct dependency of apps/web so bun resolves drizzle-orm to the same physical copy (matching peer-dep context). Both now point to drizzle-orm@0.45.2+5e256c5e4025de97.
6 Deviation Memory configured directly on the agent, not as a Mastra-level memory registry entry. The docs show both patterns; having it on the agent is simpler and explicit. Resolved. Memory (PgStore, lastMessages=40, no semantic recall, no working memory) set on the agent.
7 Deviation Weather agent file not deleted. The handoff says "delete both [weather-agent and weather-tool]". The files still exist on disk (agents/weather-agent.ts, tools/weather-tool.ts) but are no longer imported or referenced by the Mastra instance. Low priority. Files are dead code; can be cleaned up in any subsequent commit.
8 Gap Chat creation flow doesn't exist yet. The /api/chat POST route assumes a chat row already exists (looked up by chatId). The creation of a chat (choosing datasource, pinning the latest snapshot) is a Phase 1/2 concern or a separate UI flow not yet built. Pending UI/Phase 1–2. No clash — Phase 4 only handles streaming for an existing chat.
9 Deviation LLM_MODEL is z.string().min(1), not validated as provider/model format. The Mastra model router will error at runtime if the format is wrong, but we don't fail at env-parse time. Acceptable for MVP. Runtime validation provides clear error if the model string is wrong.
